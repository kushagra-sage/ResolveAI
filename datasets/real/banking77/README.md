# BANKING77 external-validation data

Downloaded from the official PolyAI repository at the commit recorded in `manifest.json`; files are checksum verified. The upstream dataset is licensed CC BY 4.0. Cite Casanueva et al. (2020), *Efficient Intent Detection with Dual Sentence Encoders*, DOI: 10.18653/v1/2020.nlp4convai-1.5.

This dataset is used only for external intent and benign-input safety validation. It does not contain ResolveAI action, policy, retrieval, or business-outcome labels.
